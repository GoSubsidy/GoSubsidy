# Route integration

Import:
import Dashboard from "./pages/Dashboard/Dashboard";
import ServiceCategory from "./pages/Services/ServiceCategory";

Add routes in your existing React Router configuration:

<Route path="/" element={<Dashboard />} />
<Route path="/services/:slug" element={<ServiceCategory />} />

IMPORTANT:
If your existing Home/Dashboard route is not "/", keep your current route and place
the Dashboard component at that route instead.

The JSX uses Bootstrap Icons classes (bi bi-*). Your project already appears to
use bootstrap-icons. If not, add:
import "bootstrap-icons/font/bootstrap-icons.css";
